# Interactive Table of Elements

A lightweight, interactive periodic table web application built with Python, Streamlit, and Plotly.

This app displays all **118 elements** in a full periodic table layout—including Lanthanides and Actinides. Users can filter elements by **Period** (rows), **Group** (columns), or **Chemical Category** to explore trends in electron shells and valence electrons.

## Features

- **Full Grid Layout:** Visualizes all 118 elements cleanly with proper Lanthanide/Actinide positioning.
- **Interactive Filtering:** Filter by Period (1–7) or Group (1–18).
- **Interactive Hover & Tooltips:** Inspect element symbols, atomic numbers, groups, periods, and categories.
- **Data Table View:** Generates a filtered data summary table dynamically below the grid.
